## One conversation at a time

The panel lists the shells of the session you are in. A project's shells all mixed together is how
the panel stops making sense, so switching conversations changes what you see — without stopping
anything. Press <kbd>s</kbd> in the console to widen it to the whole project and back.

## The panel

A dock under the chat with a tab per shell, the selected shell's live screen, and the health of each
one at a glance. `ui.dockHeight` sets how tall, `ui.dockOpen` whether it starts open.

## The console

Full screen, one shell at a time.

| Key | Does |
| --- | --- |
| <kbd>i</kbd> | Type into the shell |
| <kbd>tab</kbd> | Switch between the screen and the agent's numbered log |
| <kbd>/</kbd> | Filter the log — matches highlighted, line numbers kept |
| <kbd>?</kbd> | Details: command, folder, timing, watcher, log file |
| <kbd>[</kbd> <kbd>]</kbd> | Previous / next shell |
| <kbd>s</kbd> | This session only, or the whole project |
| <kbd>r</kbd> · <kbd>x</kbd> · <kbd>c</kbd> | Restart · stop · interrupt |
| <kbd>n</kbd> | Start a new shell yourself |
| <kbd>esc</kbd> | Back to the conversation |

Filtering happens in the daemon, so a 40,000-line dev server costs nothing to search.

## Commands

`/shells` toggles the panel, `/shell` opens the console, `/shell-new` starts one,
`/shells-clear` forgets finished shells, `/shells-restart-daemon` replaces a daemon running older
code. Rebind them under `ui.keybinds`.
